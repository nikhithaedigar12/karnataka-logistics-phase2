# Karnataka Logistics Phase 2 - Hypergraph AI System

## Overview
This project is an AI-powered Hypergraph Knowledge Graph system developed for workforce and logistics intelligence.

The system connects:
- Workers
- Jobs
- Employers
- Skills

using:
- FastAPI
- Knowledge Graphs
- AI Embeddings
- Similarity Matching
- Recommendation Systems

---

## Features

- Worker Data API
- Knowledge Graph Builder
- AI Embedding Generator
- Skill Similarity Engine
- Recommendation Engine
- Graph Visualization
- FastAPI REST APIs

---

## Technologies Used

- Python
- FastAPI
- NetworkX
- SentenceTransformers
- Scikit-learn
- Matplotlib

---

## APIs

### Workers API
`/workers`

### Graph API
`/graph`

### Embeddings API
`/embeddings`

### Similarity API
`/similarity`

### Recommendation API
`/recommend/{skill}`

### Visualization API
`/visualize`
